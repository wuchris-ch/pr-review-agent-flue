## Guarantees checked independently of model accuracy

The host parses hunk coordinates, supplies file/line locations, requires eligible source anchors, checks exact quoted substrings, and verifies the complete input digest. It rejects malformed, truncated, overlapping, oversized, or unsupported patches. Related context comes from complete hunks in the supplied diff under explicit byte, hunk, and partition limits. These checks establish source provenance; semantic correctness remains a separate evaluation question.

The watcher resolves an immutable merge-base/head diff, explicitly binds the GitHub review to its head commit, and records base/head/diff identity in a receipt. It rechecks revision changes around analysis and publication and reconciles saved receipts after lost responses or restarts. Tests cover pushes before fetch, during fetch/analysis/publication, base changes, foreign or stale receipts, lost review/status responses, pagination, and response limits. GitHub writes remain separate operations, so the implementation does not claim atomic publication across branch updates.

The combined release passed all 97 tests in 14 files, TypeScript checking, a production build, and eight independent base/head fixture checks. The dependency audit reported zero vulnerabilities. SHA-256 comparisons confirmed that the compiled CLI, reviewer, evidence validator, prompts, and model runtime matched the measured candidate after the watcher changes were integrated.
